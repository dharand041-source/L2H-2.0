# Learn-2-Hire 2.0: System Validation & Testing Framework

## 1. Overview & Evaluation Principles
The **Innovation Validation Lab** provides evaluators, judges, and auditors with reproducible, programmatic verification of the 9 core subsystems comprising Learn-2-Hire 2.0.

In strict adherence to engineering integrity:
- All reported test outputs are generated by **executable code**.
- No test outputs, user cohort stats, or mock placement percentages are fabricated.
- Controlled laboratory testing validates component integration before deployment in operational university environments.

## 3. Running Validation Tests

### 3.1 Via Command Line (Node.js / tsx)
```bash
# Run complete adaptive career engine verification suite
npx tsx scripts/test-adaptive-career-engine.ts

# Run universal question bank & blueprint verification (850 assertions)
npm run test:universal

# Run role switch context isolation matrix (35 assertions)
npx tsx scripts/test-role-switch-matrix.ts

# Run real voice input & speech recognition pipeline (26 assertions)
npx tsx scripts/test-speech-recognition.ts

# Run personalized curriculum & skill gap remediation suite (13 assertions)
npx tsx scripts/test-curriculum-engine.ts
```

### 3.2 Via In-App Validation Lab UI
1. Navigate to `/app/validation` (or public landing `/validation`).
2. Click **"Run All 12 Test Cases"** in the top banner.
3. Observe live execution telemetry, test runtimes, and verified inputs/outputs.
4. Switch to **"3. Interactive SEVA Demonstration"** for the step-by-step evaluator walkthrough.
